# JavaScript Promises - Division Practice

A simple web application demonstrating how JavaScript Promises work by handling asynchronous operations, success states (`resolve`), and error handling (`reject`) for division operations (including division by zero).

---

## 📌 Features

- **Promise Handling:** Evaluates division operations asynchronously using `resolve` and `reject`.
- **Error Catching:** Catches division-by-zero errors gracefully and outputs a descriptive message.
- **Dynamic DOM Rendering:** Displays test case steps and final results directly on the webpage.
